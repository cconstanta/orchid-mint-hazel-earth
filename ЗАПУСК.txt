Столовая «Перемена» — запуск с флешки, без установки
====================================================

Нужен портативный Node.js (архив .zip), не установщик .msi.

Структура флешки:

    F:\
      node\                 <- распакованный Node, внутри node.exe
      delta-main\           <- проект
        START.bat
        package.json
        ...

1. Скачайте Windows Binary (zip) с https://nodejs.org
   (страница Downloads → Windows Binary .zip, 64-bit).

2. Распакуйте архив. Папку переименуйте в node.
   Проверка: должен быть файл F:\node\node.exe
   (рядом лежат npm.cmd и npx.cmd).

3. Проект положите на ту же флешку, например F:\delta-main.

4. На компьютере, где ЕСТЬ интернет, один раз:
   откройте START.bat двойным щелчком.
   Он сам сделает npm install и запустит сайт.

5. В браузере: http://localhost:8080
   Гость — без входа. Сотрудникам — код 2468.

6. На компьютере преподавателя интернет уже не обязателен,
   если папка node_modules уже появилась на флешке.

Остановить сайт: окно чёрное, Ctrl+C.

Если START.bat пишет «Node.js не найден» —
папка node лежит не там: она должна быть РЯДОМ с проектом
или в корне флешки.

PythonAnywhere этот проект не запустит (там Python, здесь Node.js).
